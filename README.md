# EmailTester.py
# 🧪 SMTP Debugger Deluxe™ 3000

**¿Cansado de que enviar un simple correo electrónico sea tan aburridamente fácil? ¿Echas de menos esos momentos de frustración absoluta intentando configurar servidores SMTP?**

¡No busques más! Este script es la solución *sobredimensionada* a un problema que probablemente tengas una vez cada 5 años.

## ✨ Características *Increíblemente Útiles*

- **🚀 Debugging Nuclear**: Porque a veces necesitas 200 líneas de log para saber que te equivocaste en la contraseña
- **🔍 Resolución DNS épica**: Descubre que tu servidor existe (o no) con un dramatismo digno de Hollywood  
- **🤝 Saludo protocolario**: El script y el servidor SMTP se saludan educadamente antes del inevitable fracaso
- **📧 Autodestrucción programada**: Te envías un correo a ti mismo para confirmar que... puedes enviarte correos a ti mismo

## 🎯 ¿Para qué sirve *realmente*?

Para esas ocasiones en que:
- Tu jefe insiste en usar el servidor de correo interno que implementaron el año '98
- Has probado 3 clientes de email diferentes y ninguno funciona
- Necesitas culpar a *algo* que no sea tu configuración
- Quieres sentir que estás en *Matrix* mientras debuggeas protocolos de los 80

## 🏆 Logros Destacables

- ✅ Convierte 2 minutos de problema en 2 horas de debugging "divertido"
- ✅ Te hace sentir como un hacker de película cuando finalmente funciona
- ✅ Genera más logs que un servidor de producción
- ✅ Incluye emojis para hacer el fracaso más colorido
